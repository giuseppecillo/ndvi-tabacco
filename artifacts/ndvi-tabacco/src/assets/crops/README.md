# Module heading photographs

These decorative photographs are served locally; loading a heading makes no
request to the photo providers. Square-cropped and converted to WebP.

- `tobacco.webp`: **Ken Hammond / USDA**, public domain (PD-USGov-USDA).
  Source and licensing: https://commons.wikimedia.org/wiki/File:Tobacco.jpg
- `wheat.webp`: Unsplash photograph, “Green wheat field with distant mountains
  and house”, under the Unsplash licence: https://unsplash.com/license
  Source: https://images.unsplash.com/photo-1759134461923-ed0ce672cf4c

The images are illustrative, not measurements or evidence of nutritional status.
